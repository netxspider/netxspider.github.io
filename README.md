## ⚡ Overview

An interactive, high-performance web experience showcasing technical projects, full-stack systems, computer vision models, and engineering narratives.

- **Frontend:** React 19, TypeScript, Tailwind CSS, Framer Motion, GSAP
- **3D & Physics:** Three.js, React Three Fiber, React Three Rapier
- **Deployment:** Vercel ([netxspider.vercel.app](https://netxspider.vercel.app))

---

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/netxspider/netxspider.github.io.git

# Navigate to project directory
cd netxspider.github.io

# Install dependencies
npm install

# Start development server
npm start
```
